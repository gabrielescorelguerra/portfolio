### Tipografia

- Fonte: Nunito
- Tamanho
    - Corpo de texto: 16-18px
    - Texto pequeno (legendas, metadata): 13-14px
    - Subtítulo: 20-24px
    - Título de seção (H2): 28-36px
    - Título principal (H1/hero): 48-72px (em portfólios minimalistas às vezes vai bem maior, 80-120px, como elemento gráfico)

    > (só uma ideia, cada nível ~1.25 a 1.5x o anterior)
    - normalmente reduz tudo proporcionalmente — um H1 de 72px no desktop pode cair pra 36-40px no celular
- Line height
    - geralmente 1.4-1.6 pra corpo de texto, e mais apertado (1.1-1.3)
